# VoxVeritas - Crowd-Sourced News and Fact-Checking Platform

## PROJECT OVERVIEW
VoxVeritas is a comprehensive full-stack web application designed to combat misinformation through community-driven fact-checking and AI-powered content verification. The platform combines user participation, expert validation, and advanced artificial intelligence to ensure accurate and reliable news dissemination.

## CORE MISSION
To create a trustworthy news ecosystem where community members and experts collaborate to verify information accuracy, powered by cutting-edge AI technology to identify and flag potentially misleading content.

## COMPLETE FEATURE SET

### 1. USER MANAGEMENT SYSTEM
**Multi-Role Architecture:**
- **onlookers**: Can only explore the website.
- **Community Users**: Participate in voting on news validity and engage in discussions (requires admin approval)
- **Expert Users**: Provide professional opinions and expert analysis (must be verified journalists)
- **Admin Users**: Manage platform operations, approve users, and oversee content moderation

**Authentication & Authorization:**
- JWT-based secure authentication system
- Role-based access control
- Profile management with image uploads
- User verification system for experts

**Advanced Face Login System (Anti-Spam & Multi-Account Prevention):**
- **ArcFace Embedding Technology**: Implementation of ArcFace deep learning model for accurate facial recognition
- **Face Embedding Database**: Secure storage of facial embeddings (not actual images) for user verification
- **Duplicate Account Detection**: Automatic detection and prevention of multiple accounts by the same individual
- **Spam Account Prevention**: Real-time facial verification to eliminate bot accounts and fake registrations
- **Privacy-First Approach**: Only mathematical face embeddings are stored, ensuring user privacy protection
- **Biometric Authentication**: Optional face login as an alternative to traditional password authentication
- **Account Integrity Verification**: Continuous monitoring to maintain platform authenticity and prevent abuse
- **Real-Time Face Matching**: Instant comparison of face embeddings during login and registration processes

## PROJECT STRUCTURE

### Backend Organization:
```
backend/
├── controllers/          # Route handlers and business logic
├── models/              # Database schemas and models
├── routes/              # API route definitions
├── services/            # Business logic and AI services
├── middlewares/         # Authentication and validation
├── migration/           # Database migration scripts
├── faceRecognitionWorkflow/ # ArcFace biometric authentication system
│   ├── models/          # Face embedding models and ArcFace implementation
│   ├── preprocessing/   # Face detection and image preprocessing
│   ├── matching/        # Face embedding comparison and matching algorithms
│   ├── database/        # Face embedding storage and retrieval
```
