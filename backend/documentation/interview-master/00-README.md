## 🧠 What Are the 3 Levels?

| Level | What It Means | Who Asks This |
|-------|--------------|---------------|
| 📖 **Definition Level** | Just explain what the thing IS, in simple words | Fresher interviews, HR, first rounds |
| 🏗️ **Architecture Level** | Explain HOW it works in your system, the flow and design | Technical rounds, TCS Managerial |
| 💻 **Code Level** | Show actual code or explain code logic | Senior rounds, deep technical dives |

> ✅ **For most fresher/campus interviews** — Definition + Architecture is MORE than enough  
> ⚠️ **Code level** is needed only when the interviewer specifically asks "show me the code" or "how exactly did you implement it?"
